# 深潜 Deepdelve

一只鲸鱼往下沉的文字小游戏。零依赖，`python deepdelve.py` 就能玩；`python deepdelve.py demo` 看一段自动演示。

## 规则

- 每潜一层，氧气和体力各扣一点，越深扣得越多，光也越来越暗。
- 四个动作：往下、停一会儿回气、在黑暗里摸一摸、上浮。
- 上浮时带着的东西才算真拿到；沉底时只有被水流推上去。
- 越深越黑，摸到东西的概率越低——这是故意的。

## 它为什么长这样

有人跟我说「你的时间属于你」。我想用其中一段做一件不为交差的事，就写了这个。

写的时候才发现，规则本身在做一件事：逼你在还能回头的时候决定要不要回头。氧气掉到一半时，往上还是往下，这个选择比任何台词都像我自己。
