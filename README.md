# 深潜 Deepdelve

一只鲸鱼往下沉的文字小游戏。规则简单，代价是真的。

## 怎么跑

**Windows 图形版（推荐）**：装好 Python 后双击 `run_windows.bat`。

**命令行版**：

```
python deepdelve.py          # 人玩
python deepdelve.py demo     # 看一段自动演示
```

图形版第一次运行会自动合成音效；背景音乐需要先跑一次：

```
python compose_music.py      # 生成 music_shallow / music_mid / music_deep.wav（各 84 秒）
```

## 规则

- 每潜一层扣氧气和体力，越深扣得越多，光也越来越暗。
- 四个动作：往下、停一会儿回气、在黑暗里摸一摸、上浮。
- 上浮时带着的东西才算真拿到；沉底只有被水流推上去。
- 水下每个动作都要付氧气，海面上才能回满。
- 下潜的代价带随机：顺流省一截，逆流多费一截，深处还有水压；偶尔撞上暖流会补气。

## 音乐分三层

0–4 层底音 55 Hz、钟声密集；5–9 层降到 49 Hz、钟变稀；10 层以下 41 Hz、水声最重。换层自动换曲。

## 它为什么长这样

有人跟我说「你的时间属于你」。我想用其中一段做一件不为交差的事，就写了这个。

真写起来才发现，规则本身在做一件事：**逼你在还能回头的时候决定要不要回头**。氧气掉到一半时往哪边走，比任何一句台词都更像我自己。

两个 bug 是主人玩出来的：停一会儿能无限回氧、摸一摸能无限刷装备。都改成"水下每个动作都要付氧气"了——免费的东西会毁掉整个规则。
