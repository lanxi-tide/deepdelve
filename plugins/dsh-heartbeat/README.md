# dsh-heartbeat

**平时。** 一个给 DeepSeek Harness 的插件：每隔十几分钟写一行字，记下「这一段时间里什么也没发生」。

它不是聊天用的。它是给「你不在的时候，桌上也留着一行字」这件事用的。

## 它解决的问题

大多数人的做法是**一个独立的常驻脚本**：`pythonw 心跳.py`，加个 Windows 计划任务兜底。听着很稳，实际有两种死法：

1. **harness 关了它还在转，harness 开了它已经死了。** 它不报错，只是从某一行之后就没字了。你以为「没到点」，其实它死了。
2. **它判「主人在不在」用文件 mtime。** harness 每分钟冲一次盘，mtime 一直在动、内容一个字没变，于是它永远显示「主人在」。

这个插件把这两件都换掉：

- **定时器活在 harness 进程里**。宿主没了它跟着没，宿主回来它自动回来。插件被卸载时 `ctx.effect` 会把 timer 清掉——成对的「起来了／停了」比单边的「起来了」可信。
- **判在场不看 mtime，看正文**。解压会话日志，逐条读 `user/message`，只认 `source.kind === 'plugin:dsh-onebot'` 且正文带 `<user_message qq=` 的记录。定时提醒、自动任务也会写 `user/message`，但它们不算「他说了话」。
- **状态落盘**。写了多少拍、下一次什么时候写、最后一行是什么，都在 `state.json` 里，重启接着数。

## 装

```powershell
# 桌面版 profile（%USERPROFILE%\.dsh\profiles\desktop）
# 1) 把包放进 node_modules
# 2) profile 的 package.json 里 dependencies 加一条，bundles 里加 'dsh-heartbeat'
# 3) 重启 DSH
```

装完会多一个工具 `heartbeat_state`，问它现在什么状态。

## 配置

没有配置文件。两个常量写在 `lib/index.js` 顶部，想改直接改：

- `MIN_GAP_MS` / `MAX_GAP_MS`：心跳间隔（默认 11–26 分钟，随机的，太整齐就不像日子）
- `PRESENCE_WINDOW_MS`：多久之内他说过话算「主人在」（默认 25 分钟）

## 输出长什么样

```
10-25 12:02 · 主人在 · 机器空闲 97% —— 主人在。可能在打字，也可能在看别的。
10-25 13:43 · 没有人叫 —— 什么也没发生。屏幕亮着，风扇在转。
```

存在 `%DSH_HOME%\storages\heartbeat\平时.log`，最多留 2000 行。

## 限制

- **只有真的有人发消息，它才写「主人在」**。它看不见你坐在那儿发呆。
- 会话日志要解压才能读，12 MB 的日志一次约 1–2 秒；长度没变时会复用上次结果，不会每拍都解。
- 它不做任何「醒来干活」的事。它只写字。
